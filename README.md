# NIGHT DRIVE — after dark

Короткий вертикальный клип, смонтированный из трёх видео из этого репозитория:
ночная парковка, мокрый асфальт, синяя «копейка» и отражения фар.

| | |
|---|---|
| **Файл** | `night_drive.mp4` (основной, 48 МБ), `night_drive_preview.mp4` (720p, 24 МБ), `poster.jpg` (обложка) |
| **Хронометраж** | 30.000 с = 16 тактов по 128 BPM, ровно 900 кадров |
| **Формат** | 1080×1920 (вертикальный), 30 fps, H.264 High CRF 21 / preset slow, BT.709, ~13 Мбит/с |
| **Звук** | AAC 320 kbps / 48 kHz, оригинальный синтезированный саундтрек, −9.8 LUFS, true peak −2.0 dBTP |

## Что сделано

- **Музыка** — полностью оригинальный электронный трек, синтезированный с нуля
  (`make_music.py`): 128 BPM, 16 тактов, структура `intro → build → DROP 1 →
  breakdown → build → DROP 2 → outro`. Кик, клэп, хэты, саб-бас, арпеджио,
  пэды, стабы, райзеры, импакты, реверб, пинг-понг дилей и sidechain-pumping.
  Никаких сторонних/лицензионных аудио — трек можно использовать свободно.
  Лёгкий фон двигателя взят из исходного видео и приглушён до −25 дБ.
- **Монтаж** — 25 планов, все склейки и зум-панчи привязаны к сетке бита
  (границы квантованы до кадра, погрешность ≤ 17 мс). Быстрые планы на дропе
  (2 бита), длинные атмосферные планы в интро/брейке/аутро (4 бита).
- **Эффекты** — кинематографический грейд (поднятые тени, холодные тени /
  тёплые блики), bloom по фарам и фонарям, мягкая виньетка, зерно, резкость,
  beat-synced zoom-punch и «ручная» тряска, slow-mo на геройских планах,
  RGB-split/глитч-вспышки, hflip для разнообразия направления движения,
  24 xfade-перехода (`fade`, `hblur`, `pixelize`, `wipe`, `radial`, `zoomin` …),
  белые импакт-кадры на обоих дропах, тёплые/холодные световые засветки,
  титры на Montserrat и тонкий прогресс-бар внизу.
- **Три исходника использованы все**: `19170840349292.mp4` — широкие планы и
  отражения, `19170851359340.mp4` — крупные планы машины,
  `19170882882156.mp4` — проезды «в камеру» и hero-кадры.

## Воспроизведение / пересборка

```bash
pip install numpy scipy pillow imageio-ffmpeg
python3 make_music.py     # work/music.wav  — 30 с саундтрека
python3 make_clip.py      # work/shots/*   — 25 планов
                          # night_drive.mp4 — финальная сборка
```

Нужен ffmpeg с `libx264`, `drawtext` и `xfade` (бинарник из `imageio-ffmpeg`
подходит). Промежуточные файлы складываются в `work/` и в Git не попадают.
Повторный запуск переиспользует уже отрендеренные планы:

```bash
FORCE_SHOTS=1 python3 make_clip.py   # перерендерить все планы
MASTER_ONLY=1 python3 make_clip.py   # только финальная сборка
```

`make_clip.py` детерминирован: список планов, переходы, грейды и тайминги
лежат в константах `CUTS`, `SHOT_DEFS`, `TRANSITIONS`, `LOOKS`.

## Контроль качества

- 900 кадров, 30.000 с, видео и аудио совпадают по длительности;
- `blackdetect` / `freezedetect` — ни чёрных, ни замороженных фрагментов;
- `ebur128`: интегральная громкость −9.8 LUFS, LRA 5.1 LU, true peak −2.0 dBTP
  (запас до клиппинга после AAC-кодирования);
- файл мастера < 50 МБ — без предупреждения GitHub о больших файлах.

Шрифты Montserrat (SIL Open Font License) и текст лицензии лежат в `assets/`.
